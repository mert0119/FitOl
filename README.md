# FitOl - Fitness & Diyet Takip
 
Kişisel fitness ve diyet takip uygulaması. AI destekli yemek tanıma, barkod tarama, kalori ve makro takibi.

## Özellikler
- 📸 AI ile fotoğraftan yemek tanıma
- 📷 Barkod ile ürün tarama
- 🍽️ Kalori ve makro besin takibi
- 💪 Egzersiz kaydı ve programları
- 💧 Su takibi
- 📊 Detaylı raporlar ve grafikler
- 📱 PWA - telefondan uygulama gibi kullan

## Kurulum
```bash
pip install -r requirements.txt
python app.py
```
